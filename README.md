# Calculadora Simples

Aplicação desenvolvida em Python para realizar operações matemáticas básicas por meio do terminal.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar os fundamentos da linguagem Python, incluindo variáveis, tipos de dados, entrada e saída de informações e operadores aritméticos.

## Funcionalidades

- Leitura de valores numéricos.
- Execução de operações matemáticas.
- Exibição dos resultados no terminal.

## Tecnologias

- Python
- Git
- GitHub

## Como executar

**Pré-requisito:** Python instalado.

1. Clone o repositório:

   ```bash
   git clone git@github.com:cauarpmarques/Calculadora_Simples.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Calculadora_Simples
   ```

3. Execute o arquivo Python:

   ```bash
   python calculadora.py
   ```

   Substitua `calculadora.py` pelo nome real do arquivo, caso seja diferente.
